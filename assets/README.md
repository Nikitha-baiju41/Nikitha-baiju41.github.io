# Nikitha Baiju — Portfolio

A clean, editorial, animated portfolio for Nikitha Baiju, built for GitHub Pages with plain HTML, CSS and JavaScript.

## Structure

- `index.html` — portfolio content and semantic structure
- `style.css` — responsive visual system and animations
- `script.js` — scroll reveals, cursor interaction, magnetic buttons, tilt and navigation
- `assets/profile.jpg` — add/keep Nikitha's profile photo here
- `assets/resume.pdf` — add/keep the current resume here

## Preview locally

Use any static server, for example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## GitHub Pages

Replace the existing `index.html`, `style.css`, and `script.js` in the portfolio repository. Keep the existing `assets` folder if it already contains `profile.jpg` and `resume.pdf`.
